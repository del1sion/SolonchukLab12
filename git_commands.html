Основні команди Git

Створення репозиторію

Створити репозиторій у поточному каталозі:

git init

Клонувати віддалений репозиторій:

git clone my_url

Перегляд стану

Показати стан файлів:

git status

Переглянути зміни:

git diff

Показати історію комітів:

git log

Робота з гілками

Показати гілки:

git branch

Показати локальні та віддалені гілки:

git branch -av

Перейти на гілку:

git checkout my_branch

Створити гілку:

git branch new_branch

Об’єднати гілку:

git merge branch_a

Підготовка та коміт

Додати файл до індексу:

git add [file]

Додати всі зміни:

git add .

Створити коміт:

git commit -m "commit message"

Скасування змін

Прибрати файл з індексу:

git reset [file]

Повернутися до останнього коміту:

git reset --hard

Синхронізація

Отримати зміни з сервера:

git fetch

Отримати та об’єднати зміни:

git pull

Надіслати локальні коміти:

git push
